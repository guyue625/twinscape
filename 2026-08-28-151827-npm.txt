  产物结构

  packages/core   →  @twinscape/core    纯 Three.js，零框架依赖
  packages/vue    →  @twinscape/vue     Vue 3 composable
  packages/vue2   →  @twinscape/vue2    Vue 2.7 composable，API 与 vue 一致

  Vue 2 / Vue 3 拆两个包而不用 vue-demi
  合成一个：各自类型定义干净，不用条件解析。真正的逻辑都在
  core，适配层只把事件映射成 ref，重复代码很少。

  最小调用

  import { createTwinViewer } from '@twinscape/core'

  const viewer = createTwinViewer('#stage')
  await viewer.load('/models/pump.glb')

  两行出模型。容器传选择器或 DOM
  元素都行，灯光、轨道控制器、尺寸自适应、资源回收全部内置。

  Vue 3：

  vue
  <script setup>
  import { useTwinViewer } from '@twinscape/vue'

  const { containerRef, parts, selectedPart, isLoading, load, select } =
    useTwinViewer({ modelUrl: '/models/pump.glb' })
  </script>

  <template>
    <div ref="containerRef" class="stage">
      <div v-for="p in parts" :key="p.id"
           :style="{ left: `${p.x}px`, top: `${p.y}px` }"
           @click="select(p.id)">{{ p.name }}</div>
    </div>
  </template>

  Vue 2.7 只换 import 路径。

  API 表面

  // 模型
  viewer.load(url, { onProgress })   // 按扩展名识别，返回 Object3D
  viewer.setModel(object3D)          // 已有 Object3D 直接塞进去
  viewer.clear()

  // 部件
  viewer.getParts()                  // [{ id, name, type, x, y }]
  viewer.getPart(id)
  viewer.getObject(id)               // 拿底层 Mesh / Group

  // 选中
  viewer.select(id | null)
  viewer.getSelectedId()
  viewer.setHighlightColor('#f56c6c')
  viewer.setHighlightBlink(true)

  // 相机
  viewer.focusOn(id)                 // 带缓动，可关
  viewer.resetCamera()
  viewer.screenshot()

  // 事件
  viewer.on('select', part => {})
  viewer.on('parts', parts => {})    // 标签坐标变化时触发
  viewer.on('load:start' | 'load:end' | 'load:error' | 'resize', fn)

  // 逃生舱
  viewer.scene / viewer.camera / viewer.renderer / viewer.controls

  viewer.dispose()

  逃生舱是有意留的。你在项目里碰到包没做的功能，随时能拿原生对象自己写，不用等我
  加也不用 fork。

  配置

  按域分组，全部有默认值，什么都不传就能跑：

  createTwinViewer('#stage', {
    camera:      { fov, near, far, positionFactor, distanceFactor },
    renderer:    { antialias, pixelRatioLimit, alpha, clearColor },
    lights:      { ambient, directional, hemisphere, fill },  // 传 false 
  关掉某盏
    controls:    { enableDamping, minDistanceFactor, maxDistanceFactor },
    model:       { targetSize, initialRotation, centerAtOrigin },
    parts:       { shouldInclude },
    label:       { offset: { x, y }, anchor },
    highlight:   { color, opacity, dimOpacity, outline: {...}, blink: {...} },
    interaction: { pickEvent, enabled },
  })
