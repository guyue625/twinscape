# Twinscape 文档国际化设计

## 目标

为 Twinscape 文档建立中文优先的中英双语结构，并将 Vanilla 模型示例的界面文案改为中文。中文是默认体验，英文内容继续保留；本次不调整文档站的视觉主题。

## 文档路由

- 简体中文使用根路径 `/`，包括首页、指南、API、配置、示例和更新日志。
- 英文使用 `/en/` 前缀，保留与中文一致的页面结构。
- VitePress 使用官方 `locales` 配置生成两套导航、侧栏和界面文案。
- 页面右上角提供语言切换入口；语言切换指向另一语言的对应页面。
- 本地搜索分别索引中文和英文内容。

## 内容结构

中文页面保留现有根目录文件位置，并将正文、标题、代码说明和首页宣传文案完整翻译为简体中文。现有英文页面移动到 `en/` 下的镜像目录：

```text
apps/docs/
├── index.md
├── guide/
├── api/
├── examples.md
├── changelog.md
└── en/
    ├── index.md
    ├── guide/
    ├── api/
    ├── examples.md
    └── changelog.md
```

代码示例中的 API 名称保持英文，以确保示例可以直接复制运行。

## 模型示例

`examples/vanilla` 不引入运行时语言切换系统。页面标题、表单、状态、操作提示、Fallback 模型部件名称和错误状态直接改为中文，默认即为中文体验。

## 边界与兼容性

- 不改变 `@twinscape/core` API。
- 不改变模型页面已有布局、配色或交互方式。
- 不引入额外国际化依赖。
- 英文旧根路径会变为中文页面；英文内容的新稳定路径为 `/en/`。

## 验证

- 构建 VitePress，确认中英文全部页面可生成。
- 检查中文根导航及 `/en/` 英文导航链接。
- 构建 Vanilla 示例，确认中文文案修改不影响 TypeScript 与前端产物。
- 扫描默认文档页面和模型页面，避免遗漏主要英文界面文案。
