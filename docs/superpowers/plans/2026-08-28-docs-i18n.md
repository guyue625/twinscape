# Twinscape Documentation Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make simplified Chinese the default Twinscape documentation and demo language while preserving a complete English documentation site under `/en/`.

**Architecture:** Use VitePress's native locale routing with `root` for Chinese and `en` for English. Keep mirrored Markdown trees so every language has stable, indexable URLs; translate the static Vanilla demo directly without adding a runtime i18n dependency.

**Tech Stack:** VitePress 1.6, Markdown, TypeScript, HTML.
